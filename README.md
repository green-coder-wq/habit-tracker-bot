# Habit Tracker Bot

Сервис для трекинга привычек через Telegram-бот с бэкендом на FastAPI.

## Стек
- **Backend:** FastAPI, SQLAlchemy (async), Alembic
- **Database:** PostgreSQL
- **Bot:** pyTelegramBotAPI
- **Scheduler:** APScheduler
- **Infrastructure:** Docker Compose, Poetry
